# Ecommerce-Sales-SQL-Analysis
# E-commerce Sales Data Analysis using SQL

## Project Overview
This project focuses on analyzing e-commerce sales data using MySQL to identify business trends, customer purchasing behaviour, product performance, and revenue insights.

## Business Objectives
- Calculate total sales revenue.
- Identify best-selling products.
- Analyze revenue by product category.
- Understand customer purchasing behaviour.
- Calculate Average Order Value (AOV).
- Analyze monthly sales performance.
- Identify high-value customers.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Database Structure
The project uses four relational tables:

1. **customers** – Customer details and locations.
2. **products** – Product names, categories, prices, and stock.
3. **orders** – Order dates and order statuses.
4. **order_items** – Products, quantities, and prices in each order.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate functions: SUM(), COUNT(), AVG(), MAX()
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Subqueries and Common Table Expressions (CTEs)
- Window functions: RANK(), ROW_NUMBER(), DENSE_RANK()
- Date functions and revenue calculations

## Business Analysis
The project includes 20 SQL queries covering:
- Sales revenue analysis
- Product performance
- Customer analysis
- Order status analysis
- Monthly revenue trends
- Business performance KPIs

## Project Files
- `ecommerce_sales_analysis.sql` – SQL queries for business analysis.
